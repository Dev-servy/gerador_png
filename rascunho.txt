Você é um desenvolvedor Frontend Senior especializado em utilitários web leves, focados em performance mobile e UI/UX limpa.

Preciso que você crie um **Gerador de Posts para Instagram** voltado para dicas de programação, funcionando 100% no lado do cliente (Front-end puro, sem servidor backend). O projeto deve conter exatamente 3 arquivos separados: `index.html`, `style.css` e `script.js`.

---

### 🎯 OBJETIVO DO PROJETO
Uma aplicação web responsiva (Mobile-First) onde o usuário cola informações geradas por uma IA (Título, Código de Exemplo, Dica/Explicação Rápida, Tag/Linguagem) e o sistema estiliza isso em um layout no formato exato de um post do Instagram (1080 x 1080 pixels). O usuário pode visualizar a prévia e baixar o post em imagem PNG com um clique.

---

### ⚙️ REQUISITOS TÉCNICOS & ARQUIVOS

#### 1. `index.html`
- **Estrutura de 2 colunas/seções:**
  1. **Painel de Controle / Formulário (Entrada de Dados):**
     - Campo de texto/select: Linguagem (ex: Python, JS, HTML/CSS).
     - Campo de texto: Título do Post (ex: "Como reverter uma string").
     - Textarea: Bloco de Código de Exemplo (com o uso de Highlight.js pra estilizar o codigo do bloco e parecer realmente uma IDE).
     - Textarea: Explicação Rápida / Dica.
     - Select de Tema/Cor do Card (ex: Dark Code, Neon Synth, Clean Light, Retro Terminal).
     - Botão em destaque: "📷 Gerar e Baixar Imagem (PNG)".
  2. **Área do Post / Preview:**
     - Uma div container `#post-preview` com proporção exata 1:1 (1080 x 1080 px na renderização interna, mas escalada via CSS para caber na tela do celular sem rolar horizontalmente).
     - Estrutura interna da prévia:
       - Header do Card: Nome da Página/Handle (ex: `@algoritmo.da.vez`), Ícone da Linguagem.
       - Corpo do Card: Título chamativo, Caixa de Código estilizada estilo IDE (com bolinhas vermelha/amarela/verde no topo), Caixa de Texto explicativo.

- **Inclusão de Bibliotecas Globais via CDN (apenas o essencial):**
  - `html2canvas` (versão CDN para conversão do DOM em imagem canvas/PNG).
  - Fontes Google Fonts (ex: `Inter` ou `Poppins` para texto e `Fira Code` ou `JetBrains Mono` para código).

#### 2. `style.css`
- **Design System & Responsividade:**
  - Estilo escuro (Dark Mode) moderno para a interface do site.
  - Totalmente responsivo para telas pequenas de smartphones antigos.
  - O container `#post-preview` DEVE ter exatamente `width: 1080px; height: 1080px;` com `position: absolute` ou renderização oculta/transformada, porém usando `transform: scale(...)` para caber perfeitamente na tela do usuário sem quebrar o layout.
- **Temas do Post:**
  - Crie classes CSS para no mínimo 2 variações de cores do card do post (ex: `.theme-dark` com fundo `#0d1117`, `.theme-neon` com gradiente roxo/azul).
- **Estilização do Bloco de Código:**
  - Visual de editor de código moderno (fundo escuro, bordas arredondadas, tipografia monoespaçada).

#### 3. `script.js`
- **Funcionalidades:**
  1. **Binds em Tempo Real:** Conforme o usuário digita nos campos do formulário, o texto no `#post-preview` é atualizado instantaneamente (Live Preview).
  2. **Seletor de Temas:** Mudar a classe do `#post-preview` ao selecionar um tema no `<select>`.
  3. **Exportação de Imagem com html2canvas:**
     - Ao clicar no botão "Baixar Imagem":
     - Acionar o `html2canvas` apontando para o elemento `#post-preview`.
     - Garantir que a renderização force a escala real (1080 x 1080 px) com `scale: 2` para alta qualidade.
     - Converter em Data URL PNG e forçar o download automático do arquivo (ex: `post-instagram.png`).
     - Exibir um estado de "Gerando imagem..." no botão para dar feedback visual ao usuário.

---

### 🚫 RESTRIÇÕES
- NÃO use frameworks pesados (React, Vue, Angular).
- NÃO use Tailwind via CDN build pesado (prefira CSS puro e bem estruturado).
- Mantenha todo o código organizado, bem comentado e pronto para rodar abrindo o `index.html` direto no navegador.

Forneça o codigo completo em um unico arquivo .html

Você é um desenvolvedor Frontend Senior especializado em utilitários web leves, focados em performance mobile e UI/UX limpa.

Preciso que você crie um **Gerador de Capas de Carrossel para Instagram** voltado para dicas de programação, funcionando 100% no lado do cliente (Front-end puro, sem servidor backend). O projeto deve ser fornecido em um ÚNICO arquivo `index.html` (contendo HTML, CSS e JS embutidos), pronto para rodar direto no navegador do celular ou PC.

---

### 🎯 OBJETIVO DO PROJETO
Uma ferramenta web responsiva onde o usuário configura o **Card 1 (A Capa)** de um post em formato Carrossel para o Instagram. O layout deve ter a proporção exata de 1080 x 1080 pixels (1:1), ser ultra chamativo, visualmente limpo e otimizado para prender a atenção do usuário no feed. O usuário digita os dados, vê a prévia em tempo real e baixa a imagem em PNG com um clique.

---

### ⚙️ REQUISITOS TÉCNICOS & ESTRUTURA (Tudo dentro do arquivo index.html)

#### 1. Interface & Formulário (Painel de Controle)
- **Campos de Entrada:**
  - `Tag / Categoria`: (ex: "BIBLIOTECAS PYTHON", "DICAS HTML5", "MEME DEV").
  - `Título Principal Chamativo`: (ex: "5 Tags HTML que você DEVERIA estar usando").
  - `Subtítulo / Descrição Rápida`: (ex: "Melhore a acessibilidade e o SEO do seu site com estes elementos").
  - `Indicador de Deslize (Call to Action)`: Campo de texto ou toggle para a chamada no rodape (ex: "Arraste para o lado ➔").
  - `Seletor de Tema Visual`: Opções para trocar o visual da capa (ex: "Dark Gradient", "Cyberpunk Neon", "Minimalist Clean", "Terminal Hacker").
- **Botão Principal:** "📷 Baixar Capa (PNG)" em destaque.

#### 2. Área de Preview (#post-preview)
- **Resolução Exata:** $1080 \times 1080$ px na renderização interna, mantendo responsividade no celular através de `transform: scale()` ou max-width responsivo.
- **Elementos Visuais Internos da Capa:**
  - **Header:** Logo/Handle da página (ex: `@algoritmo.da.vez`) + Badge/Pill com a `Tag / Categoria`.
  - **Corpo Central:** 
    - Título em destaque com tipografia de alto impacto (tamanho grande, bom contraste).
    - Subtítulo complementar com leitura agradável.
    - Um elemento gráfico decorativo de fundo (como degradês sutis, pontos decorativos estilo grid ou ícones tech em SVG).
  - **Footer:** Um indicativo visual claro chamando o usuário para passar o carrossel (ex: ícone de seta piscando/em destaque ou texto "Deslize ➔").

#### 3. Dependências Globais (Via CDN no `<head>`)
- `html2canvas` (versão CDN para conversão do DOM em imagem PNG de alta resolução).
- Fontes do Google Fonts (ex: `Montserrat` ou `Inter` para títulos de grande impacto, `Fira Code` para tags).

#### 4. Estilos (CSS embutido em `<style>`)
- Tema escuro para a interface da aplicação web.
- Estilos para as variações de temas do card (#post-preview).
- Uso de Flexbox/Grid para centralizar o título e manter o visual profissional de post de redes sociais.

#### 5. Lógica (JS embutido em `<script>`)
- Atualização em tempo real da prévia conforme o usuário digita no formulário.
- Troca de temas alterando a classe CSS da div `#post-preview`.
- Função de clique no botão de download:
  - Executa o `html2canvas` com `scale: 2` para entregar uma imagem $1080 \times 1080$ px cristalina.
  - Baixa automaticamente o arquivo como `capa-carrossel.png`.

---

### 🚫 RESTRIÇÕES
- Entregue TODO o código em UM ÚNICO arquivo `index.html`.
- NÃO utilize Tailwind via CDN nem frameworks como React/Vue.
- O código deve ser limpo, bem comentado e pronto para ser executado apenas abrindo o arquivo no navegador.
